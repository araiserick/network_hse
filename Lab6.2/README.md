###  Пояснения к расчетам

1. Subnet1 (70 хостов):
   - Требуется минимум 72 адреса (70 + сетевой + широковещательный)
   - Выбрана маска /25 (128 адресов, 7 бит для хостов)

2. Subnet2 (50 хостов):
   - Требуется минимум 52 адреса
   - Выбрана маска /26 (64 адреса, 6 бит для хостов)

3. Subnet3 (30 хостов):
   - Требуется минимум 32 адреса
   - Выбрана маска /26 (64 адреса) для резервирования, так как /27 (32 адреса) не оставит запаса

4. Межмаршрутизаторные соединения:
   - Для соединений точка-точка достаточно 2 адреса
   - Выбрана маска /30 (4 адреса, 2 полезных)
