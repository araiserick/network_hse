### Вопрос для повторения

Почему маска подсети так важна при анализе IPv4-адреса?

Маска подсети критически важна, потому что она:

1. Определяет границу между сетевой и узловой частями адреса
2. Позволяет вычислить сетевой адрес путем побитовой операции И
3. Определяет количество доступных узлов в подсети
4. Позволяет определить широковещательный адрес подсети
5. Необходима для маршрутизации — роутеры используют маску для определения, находится ли адрес назначения в той же сети
6. Позволяет выполнять разбиение на подсети (subnetting) для эффективного использования адресного пространства
